# Swiggy Clone

A learning project that recreates the core functionality of Swiggy using
Spring Boot microservices.

## Architecture

- Auth Service
- Restaurant Service
- Order Service
- Notification Service
- API Gateway
- Service Discovery

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- MySQL
- Spring Cloud
- Gradle
